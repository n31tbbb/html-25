# html-25

Repository per gli esercizi di HTML, CSS e JavaScript.

## 📚 Esercizi Disponibili

### [Esercizio 1: HTML Basics](school/1-html-basics/)
Impara le basi di HTML con elementi fondamentali come headings, paragrafi e immagini.

### [Esercizio 2: Bootstrap Basics](school/2-bootstrap/) 
Crea layout responsivi utilizzando il framework Bootstrap e CSS personalizzato.

### [Esercizio 3: JavaScript Basics](school/3-javascript-basics/)
Aggiungi interattività alle pagine web con JavaScript e DOM manipulation.

## 📋 Come iniziare

1. **Vai agli [Issues](../../issues)** per trovare le istruzioni dettagliate di ogni esercizio
2. Clona questa repository o aprila in un GitHub Codespace
3. Naviga alla cartella dell'esercizio desiderato
4. Segui le istruzioni nell'issue corrispondente

## 🎯 Progressione consigliata

Gli esercizi sono progettati per essere completati in ordine:
1. **HTML Basics** → Impara la struttura base
2. **Bootstrap Basics** → Aggiungi stili e responsive design  
3. **JavaScript Basics** → Rendi la pagina interattiva
