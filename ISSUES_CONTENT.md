# Istruzioni per la creazione degli Issues GitHub

Come richiesto nell'issue #8, le specifiche dettagliate degli esercizi devono essere spostate dai file della repository agli Issues di GitHub.

## Issues da creare:

### Issue 1: "Esercizio 1: HTML Basics"
**Contenuto da includere:**
- Obiettivo: Familiarizzare con la struttura HTML di base
- Istruzioni passo-passo per creare elementi HTML
- Come creare branch, modificare files, fare commit e PR
- Uso di: `<h1>`, `<p>`, `<img>` con attributi
- Collegamenti a risorse MDN e W3Schools

### Issue 2: "Esercizio 2: Bootstrap Basics" 
**Contenuto da includere:**
- Obiettivo: Imparare Bootstrap per layout responsivi
- Istruzioni dettagliate per:
  - Inclusione Bootstrap tramite CDN
  - Creazione navbar responsiva
  - Sistema a griglia (container, row, col)
  - Componenti: cards, buttons, forms
  - CSS personalizzato e classi/ID
  - Media queries per responsive design
- Esempi completi di codice HTML e CSS
- Collegamenti alla documentazione Bootstrap ufficiale

### Issue 3: "Esercizio 3: JavaScript Basics"
**Contenuto da includere:**
- Obiettivo: Aggiungere interattività con JavaScript
- Istruzioni per:
  - DOM manipulation
  - Event listeners
  - Funzioni e variabili
  - Validazione form
  - Animazioni CSS + JavaScript
- Esempi di codice JavaScript
- Collegamenti a risorse JavaScript

## Struttura degli Issues:
Ogni issue dovrebbe includere:
1. **Titolo chiaro** (es. "Esercizio 1: HTML Basics")
2. **Etichette appropriate** (es. "exercise", "beginner", "html")
3. **Descrizione dettagliata** con istruzioni passo-passo
4. **Esempi di codice** in markdown code blocks
5. **Collegamenti alle risorse** di apprendimento
6. **Criteri di completamento** chiari

## Note:
- Le istruzioni originali erano nei file `lesson-*.md` e `solution-*.md`
- I file di esempio e codice working rimangono nella repository
- I README.md ora puntano agli Issues per le istruzioni dettagliate
